Desestructuración

Permite extraer valores de arreglos o propiedades de objetos de manera limpia y directa.

// Objetos
const user = { id: 1, name: 'Yino' };
const { name } = user;

// Arrays
const colors = ['#f7df1e', '#222'];
const [jsYellow, jsBlack] = colors;

Visión General de ES6+

Las mejoras de ES6+ permiten escribir código más limpio, legible y eficiente. Destacan características como la desestructuración, el Spread Operator, los Rest Parameters, los Template Literals y la modularización.

// 1. Modulación & Template Literals
const proyecto = "Web Portfolio";

// 2. Desestructuración & Spread Operator
const datos = { nombre: "Yino", xp: 5 };
const extra = { rol: "Dev", ...datos }; // Copia y añade (Spread)

const { nombre, rol } = extra; // Extrae variables

// 3. Rest Parameters & Template Literals
const mostrarStatus = (user, ...tags) => {
  return `El ${rol} ${user} domina: ${tags.join(", ")}.`;
};

console.log(mostrarStatus(nombre, "HTML", "CSS", "Python"));

Spread & Rest (...)

El operador de tres puntos permite expandir elementos (Spread) o agruparlos (Rest).

// Spread: Copiar y unir
const arr1 = [1, 2];
const arr2 = [...arr1, 3, 4];

// Rest: Agrupar argumentos
function sum(...nums) {
  return nums.reduce((a, b) => a + b);
}

Clases y Herencia (POO)

JavaScript utiliza prototipos, pero con 'class' podemos estructurar mejor nuestro código.

class Robot {
  constructor(name) {
    this.name = name;
  }
  saludar() { return `Hola, soy ${this.name}`; }
}

class Guerrero extends Robot {
  atacar() { return 'PUM!'; }
}
